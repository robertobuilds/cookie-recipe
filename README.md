# Cookie Recipe

#### A simple chocolate chip cookie recipe webpage, 2026

#### By **Roberto Carlos**

## Description

Cookie Recipe is a simple webpage created to practice HTML, Git, GitHub, and Markdown.

The webpage provides a chocolate chip cookie recipe, including the ingredients, preparation directions, and serving suggestions.

## Setup/Installation Requirements

1. Clone this repository to your computer.
2. Open the project folder.
3. Open `cookie-recipe.html` in your web browser.
4. No additional software or dependencies are required to view the webpage.

## Technologies Used

- HTML
- Markdown
- Git
- GitHub
- Visual Studio Code

## Features

- Recipe description
- List of ingredients
- Step-by-step preparation directions
- Serving suggestions
- Cookie image
